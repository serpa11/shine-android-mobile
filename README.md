# shinemobile
Get everyday tasks done with Shine on mobile now available in Android devices!

## Download

**[ShineMobile.apk](https://github.com/serpa11/shine-android-mobile/raw/refs/heads/main/ShineMobile.apk)** (0.64 MB)

Open the link on your Android phone and install it (your browser will ask to allow installs from this source).

- Just the Shine app — no overlay, no floating ball, no extra permissions
- Native mic/camera, screen reading ("what's on my screen"), photo & file attach
- Transparent status bar, no blue tap highlights — feels like a real app
